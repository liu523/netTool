利亚方舟海螺云网络诊断工具 Electron 2.1.0
============================================================

一、选择哪个文件

1. Windows 10/11 64位：使用 win-x64 现代版。
2. Windows 7 SP1/8/8.1：使用标有 Win7-x64 或 Win7-ia32 的兼容版。
3. macOS：Intel 芯片使用 mac-x64，Apple 芯片使用 mac-arm64。

本工具为免安装版本，自带运行环境，不需要安装 .NET、Node.js，也不依赖系统的 ping、tracert、nslookup 或 curl 命令。

二、客户现场怎么测

1. 最好在“海螺云无法访问”的当时立即运行。
2. 填写门店名称和宽带运营商。
3. 工具始终检测13个默认域名；如需检查其他系统，可在“额外诊断域名”中输入，多个域名使用换行、逗号或空格分隔。
4. 默认选择“快速诊断一次”；偶发故障建议选择“连续检测5分钟”或“连续检测10分钟”。
5. 点击“开始检测”，不要中途关闭电脑或切断网络。
6. 完成后把同一目录下生成的 TXT、HTML，以及连续检测产生的 CSV 一并发给技术人员。

三、结果说明

- HTML 是友好分析报告，可直接双击查看，也可打印为 PDF。
- HTML 中“路由跟踪诊断”会按域名显示目标IP和逐跳路径；星号只代表该跳未响应ICMP，不能单独判定中断。
- TXT 保存完整原始测试证据。
- CSV 记录连续检测中的时间序列、IP变化、故障和恢复。
- api.lyfz.net 根路径返回 HTTP 5xx，表示请求已经到达服务器，工具会按网络正常标记。

四、隐私与压力

工具只测试固定域名的 DNS、TCP 443、TLS、HTTPS响应头、网关和公网出口，不读取账号、密码、Cookie或业务内容。连续模式自有域名约每10秒一次，第三方域名约每60秒一次，单台客户电脑产生的压力很小。

五、Windows安全提示

当前开发成品未使用公司代码签名证书。Windows可能显示“未知发布者”或 SmartScreen 提示。正式外发前，建议由公司统一完成代码签名并提供SHA-256校验值。

Windows 7兼容版基于已停止安全更新的 Electron 22，只应给确实无法升级的存量电脑使用；可以使用现代版时不要使用兼容版。
